# sales-performance-analytics

📌 Objetivo

Projeto de análise estratégica de vendas com foco na construção de KPIs, geração de insights e apoio à tomada de decisão.

📊 Problema de Negócio

A empresa precisava entender:

Evolução da receita ao longo do tempo

Performance por região

Produtos mais rentáveis

Concentração de receita por cliente

Tendências de crescimento

🛠 Tecnologias Utilizadas

PostgreSQL

SQL

Python (Pandas)

Streamlit

Power BI

Git

🏗 Modelagem de Dados

Base relacional contendo informações de pedidos, produtos, regiões e valores.

📈 KPIs Desenvolvidos

Receita Total

Receita Mensal

Crescimento Mensal

Ticket Médio

Receita por Região

Top 10 Produtos

Análise de concentração (Pareto 80/20)

🔍 Principais Insights

20% dos clientes representam mais de 60% da receita

A região Sudeste lidera em faturamento

Forte crescimento sazonal no último trimestre

Categoria X apresenta alto volume, porém menor margem

📊 Dashboards

Dashboard interativo em Power BI

Dashboard web em Streamlit
